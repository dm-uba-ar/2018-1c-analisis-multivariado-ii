# Programa y bibliografía

- Se desarrollarán los siguientes procedimientos para el análisis de
  datos multivariados: coordenadas discriminantes, correlación canónica,
  biplot, h-plot, discriminación, modelo lineal multivariado, clustering y
  técnicas de árboles para clasificación y regresión. En las prácticas se
  analizarán conjuntos de datos reales usando el programa R.

- Flury, B. (2013). *A first course in multivariate statistics*.
  Springer Science & Business Media.
- Richard A. Johnson, Dean W. Wichern, *Applied Multivariate
  Statistical Analysis,* Prentice Hall.
- G. Seber, *Multivariate Observations*, Wiley.
